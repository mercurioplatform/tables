# Localization (i18n)

Пакет `mercurioplatform/tables` поставляется с двумя готовыми локалями — **ru** и **en** — и полностью переключается через `App::setLocale()` / `app()->setLocale()`. Все строки UI движка (Blade-шаблоны и runtime-JS) обращаются к `tables::<group>.<key>`.

## Loader

`TablesServiceProvider::boot()` регистрирует ресурсы через `loadTranslationsFrom(__DIR__.'/../resources/lang', 'tables')`. Namespace `tables` обязателен — он изолирует пакетные ключи от хост-приложения.

## Структура групп

Все строки разбиты на 12 файлов в `resources/lang/{ru,en}/`:

| Группа         | Файл              | Покрытие |
|----------------|-------------------|---------|
| `action_log`   | `action_log.php`  | Header-action, offcanvas, undo |
| `bulk`         | `bulk.php`        | Bar, modal form, queued/progress |
| `cell`         | `cell.php`        | Inline cell editor |
| `confirm`      | `confirm.php`     | Confirm/preview offcanvas, default labels |
| `export`       | `export.php`      | Button, confirm threshold |
| `filters`      | `filters.php`     | Filter-bar, autocomplete |
| `prefs`        | `prefs.php`       | Prefs popover, columns/density |
| `qb`           | `qb.php`          | Query Builder operators, UI |
| `row_actions`  | `row_actions.php` | Inline/form/popover |
| `saved_views`  | `saved_views.php` | Tabs, save-view modal |
| `shell`        | `shell.php`       | Page-head, generic UI |
| `summary`      | `summary.php`     | KPI/funnel cards |

## Использование в Blade

```blade
{{ __('tables::shell.cancel') }}
{{ __('tables::action_log.undo_failed', ['status' => 500]) }}
```

Плейсхолдеры — стандартные Laravel `:name`, передавайте параметры массивом.

## Использование в JS

Runtime JS получает translations через `window.TablesI18n` (PHP whitelist в `Mercurio\Tables\Support\JsTranslations::payload()`) — payload инжектится inline-скриптом в `shell.blade.php` перед Vite-бандлом.

```js
import { tablesT } from './i18n.js';

tablesT('cell.save_failed');                                  // → "Не удалось сохранить (HTTP :status)."
tablesT('bulk.progress.success_body', { affected: 3, total: 5 });
```

Если ключа нет в whitelist, helper вернёт сам ключ и один раз залогирует `console.error('tables.i18n missing key', key)`.

### Расширение whitelist

Чтобы добавить ключ для JS, отредактируйте `Mercurio\Tables\Support\JsTranslations::whitelist()` — это плоский массив в dot-notation. Изменения подхватятся при следующем рендере страницы (whitelist выполняется во время `render`, не кешируется).

## Публикация и переопределение

```bash
php artisan vendor:publish --tag=tables-lang
```

Команда копирует `ru/` и `en/` в `lang/vendor/tables/` (Laravel 13+: `lang_path()`, иначе `resources/lang/`). Любой ключ можно перекрыть, добавив строку в соответствующий файл хоста — Laravel применит override автоматически.

Чтобы добавить **другую локаль** (например, `de`), создайте `lang/vendor/tables/de/<group>.php` со всеми 12 файлами. Ключи должны совпадать с `ru/en` 1:1 — несовпадения смотрите через PHP-скрипт в этом docs-блоке или через тесты хоста.

## Config-метки как translation keys

Дефолты в `config/tables.php` для меток UI указаны как translation keys пакета:

```php
'qb_button_label'                  => 'tables::qb.button_label',
'user_prefs.popover_button_label'  => 'tables::prefs.popover_button_label',
'export.button_label'              => 'tables::export.button_label',
'action_log.header_action_label'   => 'tables::action_log.header_action_label',
```

Это значит, что:

- При переопределении конфига в хосте можно передать как **translation key** (`'app::custom.label'`), так и **готовую строку** (`'Filter'`) — read-сайты в Blade оборачивают значение в `__($value)`, поэтому подходит и то, и другое.
- При смене локали стандартные дефолты переключаются автоматически.

## System saved views с translation keys

`SavedView::scope('key', label, ...)` принимает в `label` либо обычный текст, либо translation key (`'tables::saved_views.system.all'`). `SystemViewSyncer` хранит значение в столбце `name` как есть (fingerprint стабилен, locale-independent), а Blade-компонент `<x-tables.saved-views>` рендерит через `__($view->label)` — резолвит translation keys на лету.

```php
public function savedViews(): array
{
    return [
        SavedView::all('app::tables.views.all')->default()->position(0),
        SavedView::scope('published', 'app::tables.views.published', 'published')->position(1),
    ];
}
```

## Smoke-проверка парности ключей

Все 12 файлов `ru/` ↔ `en/` имеют идентичные наборы ключей (включая вложенные subkeys типа `qb.operators.*`, `bulk.progress.*`, `confirm.preview.*`). Если добавляете новый ключ в `ru/`, не забудьте зеркальную запись в `en/`.

## Что НЕ локализовано (и почему)

- **User-defined labels** в `Field::make('column', 'Заголовок')`, `BulkAction::make(...)`, `RowAction::make(...)` — это пользовательские данные ресурса, не пакета. Хост может сам прокидывать туда `__('app::...')`.
- **Динамические значения данных** (имена user saved views, message-flash из сессии) — отображаются как-есть.
- **Bootstrap-зависимые aria-labels из самого bootstrap.js** — относятся к runtime JS-фреймворка.
